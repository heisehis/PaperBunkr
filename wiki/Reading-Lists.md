# Reading Lists

A **Reading List** is a hand-ordered sequence of issues — a reading order, a story arc, a
crossover event. Unlike [Smart Lists](Smart-Lists), the contents and order are set by you.

Open **Reading Lists** from the navigation rail. Create one from the sidebar.

## Building a list

- **Search your library by series or number…** and click to add issues.
- Reorder with the **↑ / ↓** buttons; remove with **✕**.
- Each row shows whether the issue is **Owned** or **Missing** from your library, and its
  **Read** state.
- The header summarises **TOTAL ISSUES**, **OWNED**, and **MISSING**.
- Add **Notes** to the list.

## Reading from a list

Click the **Read** action on any row to open that issue in the reader. Chapter
previous/next in the reader follows the list order.

## Import / export

| Button | What it does |
|---|---|
| **Import .CBL** | import a ComicRack/Mylar **Comic Book List** file |
| **Import .CSV** | import a list from a spreadsheet-style CSV |
| **Export .CBL** | save the list as a `.cbl` for other apps |
| **Export as Text** / **Copy as Text** | plain-text list for sharing |

## Story-arc lookup

When you name a list after a story arc or crossover, use **Search Story Arc…** to look the
arc up online and pull in its canonical issue list and synopsis, then **Use This Arc**.
This is what the **CBL Manager** browse feature is built on. **Refresh** re-checks which
issues you now own.

## Linking to a Story Event

A reading list can be **linked to a [Story Event](Story-Events-and-Relations)**
(**Link to Event** → search → **Link**). Linked, the list and the event's timeline stay
associated; **Unlink event** breaks it.

## External tracker import

Importing lists straight from AniList / MyAnimeList is shown in the UI but **deferred** —
not wired up yet in the alpha.
