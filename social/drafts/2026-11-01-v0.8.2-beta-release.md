## X (@Ehis_II)

### 1/4
Paperbunkr 0.8.2-beta is out, and this one is about books.

EPUBs now get a real library and reader: shelves, reading stats, dictionary lookup, text-to-speech, Calibre import and OPDS catalogs. 📚

### 2/4
Reading-list imports got a review step. Smart Match shows you what it matched before anything changes, keeps the entries it couldn't place, and lets you undo a link.

Tracker sync stopped dropping progress too: failed pushes now retry on their own.

### 3/4
Series know their relatives now. Paperbunkr finds related series and lines up chapters across them.

For plugin authors, API 4.5 adds scaffolding, testing helpers, new hooks and metadata sources.

### 4/4
Free and open source. Local-first: no cloud, no account, no telemetry. Windows installer that updates itself.

## Telegram

Paperbunkr 0.8.2-beta is out

This release is mostly about books, with safer reading-list imports and steadier tracker sync.

• Books library and reader: shelves, detail pages, reading stats, dictionary lookup, text-to-speech, Calibre import, OPDS catalogs
• Reading-list Smart Match: review matches before they apply, keep unresolved entries, undo links
• Tracker retry queue: failed progress pushes retry automatically, and newer progress wins
• Series connections: related-series discovery and chapter alignment
• Plugin API 4.5: scaffolding, testing helpers, new hooks and metadata sources

Also: faster guided view, better metadata handling and smoother book-reader controls.

Free, open source, local-first. Windows installer, updates itself.
