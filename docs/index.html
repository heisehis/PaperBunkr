PaperBunkr

A free, local-first desktop comic & manga library and reader for Windows. CBZ, CBR, PDF, EPUB — no cloud, no account, your library stays on your machine.

Early alpha — expect rough edges
Download latest release View on GitHub

What it does

  • Comic & manga reading — real page rendering for .cbz / .cbr / .pdf, fit modes, zoom, rotation, double-page spread, continuous/webtoon scroll, and RTL manga reading direction.
  • Books — a separate section for EPUB/PDF novels.
  • Library management — series/issue browsing, sort/group, browse history, Smart Lists, Reading Lists, and migration from an existing ComicRack CE library.
  • Home dashboard — continue reading and recommendation modules driven by a relationship-aware recommendation engine.
  • Rich metadata — series relations, continuity groupings, story events, and a live AniList adapter.

Get started

Grab the installer from the latest release. It's fully self-contained — bundles its own .NET 8 runtime, nothing else to install. Windows only for now. Full docs and build-from-source instructions are in the project README.

Built on .NET 8 and Avalonia UI. No license has been chosen yet — see the repository for current terms. Feedback and bug reports welcome via GitHub Issues.
