**What:**
1. `DetailMetaBadgeGroup : ObservableObject` exactly as specced in the design doc's §1 code block - `Visible` (first 3 or all when expanded), `OverflowCount`, `HasOverflow`, `MoreLabel`, `IsExpanded`, `ToggleExpandCommand`.
2. `IDetailHeaderSource.cs` ([:45](../../../src/Paperbunkr.App/ViewModels/IDetailHeaderSource.cs#L45)): change the default-interface-member type from `IReadOnlyList<DetailMetaBadge> MetaBadges => Array.Empty<DetailMetaBadge>();` to `DetailMetaBadgeGroup MetaBadges => new(Array.Empty<DetailMetaBadge>());`. `HasMetaBadges` ([:48](../../../src/Paperbunkr.App/ViewModels/IDetailHeaderSource.cs#L48)) changes its `.Count > 0` check to read through `.Visible.Count > 0` or add a `TotalCount` on the group - use whichever keeps `HasMetaBadges` meaning "any badge exists at all," not "any badge is currently visible" (those are the same today since there's no cap, but must stay distinct once capping exists).
3. All three view-models (`DetailScreenViewModel.cs`, `MangaDetailScreenViewModel.cs`, `BookDetailScreenViewModel.cs`, each confirmed by grep to have the identical `private IReadOnlyList<DetailMetaBadge> _metaBadges = Array.Empty<DetailMetaBadge>();` + explicit-interface `MetaBadges => _metaBadges;` pair): change the field type to `DetailMetaBadgeGroup`, wrap every existing `_metaBadges = DetailMetaBadge.Build(...)` assignment as `_metaBadges = new DetailMetaBadgeGroup(DetailMetaBadge.Build(...));`, and `BookDetailScreenViewModel.cs`'s series-mode `_metaBadges = Array.Empty<DetailMetaBadge>();` ([:424](../../../src/Paperbunkr.App/ViewModels/BookDetailScreenViewModel.cs#L424)) becomes `new DetailMetaBadgeGroup(Array.Empty<DetailMetaBadge>())`.
4. `DetailHero.axaml` ([:85](../../../src/Paperbunkr.App/Views/DetailHero.axaml#L85)): `ItemsControl ItemsSource="{Binding MetaBadges}"` → `ItemsSource="{Binding MetaBadges.Visible}"`. Add a trailing "+N more" `Button` in the same `WrapPanel` ([:82-108](../../../src/Paperbunkr.App/Views/DetailHero.axaml#L82-L108)), styled like the existing `heroBadge` chips (`Classes="heroBadge"` on a `Border` wrapping a `TextBlock`), `Content="{Binding MetaBadges.MoreLabel}"`, `Command="{Binding MetaBadges.ToggleExpandCommand}"`, `IsVisible="{Binding MetaBadges.HasOverflow}"`.
**Depends on:** none
**Verify:** `dotnet build` (compiles against the new type everywhere `MetaBadges`/`_metaBadges` is touched - the explicit-interface shape means a missed call site is a compile error, not a silent runtime miss).
